# Healthcare Eclipse 🩺✨

Welcome to the official repository for **Healthcare Eclipse**, a modern, responsive, and feature-rich frontend for a healthcare management platform. This project provides a seamless user interface for connecting patients and doctors, built with pure HTML, CSS, and JavaScript, and styled with Tailwind CSS.


## ✨ Features

- **Dynamic Landing Page:** A beautiful and engaging entry point with animated elements and smooth scrolling.
- **Dual Dashboards:** Separate, tailored dashboard views for both **Patients** and **Doctors**.
- **Authentication Mockup:** Fully functional login and registration modals that use `localStorage` to simulate user sessions.
- **Responsive Design:** A mobile-first approach ensuring the application looks great on all devices, from desktops to smartphones.
- **Dark Mode:** A sleek, user-toggleable dark theme that persists across sessions.
- **Interactive UI Elements:** Custom-styled components, loading animations, and interactive buttons provide a polished user experience.
- **Simulated Google Sign-In:** A one-click login option to demonstrate alternative authentication flows.

## 🛠️ Tech Stack

- **HTML5:** For the core structure and content.
- **CSS3 & Tailwind CSS:** For styling and a responsive utility-first layout.
- **JavaScript (ES6+):** For all interactivity, DOM manipulation, and application logic.
- **Lucide Icons:** For beautiful and consistent icons.
- **Google Fonts:** For modern typography (`Inter`).
